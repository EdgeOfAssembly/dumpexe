## Ralf Brown's Interrupt List (`interrupts/`, generated `int_db.h`)

## ne_names.h: Win16 ordinal names (from Wine)

The KERNEL, USER and GDI ordinal-to-name tables in `ne_names.h` list the
ordinal numbers and export names of the Windows 3.x system modules. They were
generated from the Wine project's 16-bit spec files (`krnl386.exe16.spec`,
`user.exe16.spec`, `gdi.exe16.spec`, https://gitlab.winehq.org/wine/wine).
Wine is licensed under the GNU LGPL 2.1 or later. Only the ordinal/name pairs
(interface facts of the Windows API) are used; no Wine source code is
included. Wine-internal pseudo-exports (`__wine_*`) were removed.

## Static release binaries

A statically linked dumpexe also contains the C and C++ runtime of the
toolchain that built it. Their license texts ship with such a binary.

- **Default `make` build** (`g++ -static -static-libstdc++`): GCC's
  **libstdc++** and **libgcc** (GPL-3.0-or-later WITH GCC-exception-3.1, the
  GCC Runtime Library Exception 3.1), plus the C library of the build host
  (glibc, LGPL-2.1-or-later, on a glibc system).
- **musl build** (musl-gcc / a musl cross g++): **musl** libc (MIT), with
  GCC's libstdc++ and libgcc as above.
- **zig build** (`zig c++`): **musl** libc (MIT) and LLVM **libc++**,
  **libc++abi** and **libunwind** (Apache-2.0 WITH LLVM-exception).
